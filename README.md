Security Practices

Security is being incorporated into the project from the beginning.

Current practices include:

GPG-signed Git commits
Git version control
.gitignore for sensitive files
Least-privilege principles
Secure credential management
Security scanning
CI/CD security checks
Infrastructure security awareness
Git Commit Signing

Git commits for this project are configured to use
GPG signing.

This provides cryptographic verification that commits were signed
using my configured developer identity.

CI/CD

The project is being developed toward an automated CI/CD pipeline
using GitHub Actions.

Detect code changes
