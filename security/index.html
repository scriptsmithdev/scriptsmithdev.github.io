DEVSECOPS SECURITY

Security from day one.

Security should not be something added after deployment. It should be part of the engineering process.

Secret Management

Avoiding hardcoded credentials and sensitive values inside source code and infrastructure configuration.

Least Privilege

Designing access around the principle that users, services and workloads should receive only the permissions they require.

Security Scanning

Using automated security checks and container scanning as part of the delivery process.

Signed Commits

Using GPG-signed Git commits as part of my source-control security practices.

CI/CD Security

Integrating validation and security checks into automated pipelines.

Shift Left

Finding security problems earlier in the software development lifecycle rather than waiting until production.

My security mindset

Secure code. Secure infrastructure. Secure credentials. Secure pipelines. Security is a continuous engineering responsibility.
