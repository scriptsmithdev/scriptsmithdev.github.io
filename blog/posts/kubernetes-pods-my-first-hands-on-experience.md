# Kubernetes Pods: My First Hands-On Experience

Today I started learning the fundamentals of Kubernetes Pods and how they are used to run containerized workloads.

## What I Learned

I learned what a Kubernetes Pod is, why Pods are the smallest deployable unit in Kubernetes, and how containers run inside Pods.

## What I Did

I created and worked with a Kubernetes Pod and practiced using `kubectl` to inspect and manage it.

For example:

```bash
kubectl get pods
kubectl describe pod my-pod
```
