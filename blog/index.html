Kubernetes: My First Steps into Container Orchestration

By Felix Amoah | DevSecOps Bootcamp

Week 1 — Kubernetes

Getting Started with Kubernetes

As part of my DevSecOps journey, I recently started learning Kubernetes. After working with Docker and understanding how containers are created and managed, Kubernetes introduced me to the bigger picture: how to manage containers at scale.

Kubernetes is a container orchestration platform that automates the deployment, scaling, and management of containerized applications. Instead of manually starting and monitoring individual containers, Kubernetes allows us to describe the desired state of our application and continuously works to maintain that state.

Why Kubernetes Matters in DevSecOps

One thing I am beginning to understand is that Kubernetes is not just about running containers. It also becomes an important part of modern CI/CD and DevSecOps workflows.

A typical workflow can involve a developer pushing code to GitHub, a CI/CD pipeline building a Docker image, security tools scanning the image, and Kubernetes eventually deploying that application into a cluster.

This makes Kubernetes an important skill for anyone interested in cloud infrastructure, automation, and DevSecOps engineering.

My First Kubernetes Environment

For my learning environment, I am using Minikube to run Kubernetes locally. Minikube provides a lightweight Kubernetes cluster that is useful for learning and experimenting without requiring a full cloud environment.

Some of the commands I have started working with include minikube start, kubectl get nodes, kubectl get pods, and kubectl describe pod.

What I Have Learned So Far

  • Kubernetes manages containerized workloads.
  • kubectl is used to communicate with a Kubernetes cluster.
  • Pods are the basic execution units in Kubernetes.
  • Minikube is useful for local Kubernetes development.
  • Kubernetes can help automate application deployment and scaling.

Next Step

My next step is to go deeper into Kubernetes Pods, Deployments, Services, ConfigMaps, and Secrets. I also want to understand how Kubernetes fits into a complete DevSecOps pipeline.

This is only the beginning, but I am starting to see how containers, infrastructure, automation, security, and application deployment connect together.
